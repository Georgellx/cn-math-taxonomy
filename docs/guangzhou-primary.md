## 待核范围

- 四、五、六年级下册整体：当前数据包含旧版与临时迁移，不声称已匹配2027春正式教材。
- 上游暂挂复习单元的变化规律、倍、集合、八个方向、优化、植树等节点。

- 积的近似数、等式性质在新教材中的范围，以及折扣、利率等百分数应用是否仍为本册必学内容。不能仅据目录省略就认定删除。

- 循环小数、商的近似数可能缺少专门节点；数学连环画、营养午餐等活动尚未单独建点。只记录待核问题，本轮不凭教辅目录补造正式节点。

## 使用行为

核对元数据保存在 `topic.curriculum_review`，状态为 `corrected`（本轮对应问题已修正）、`pending`（待核）或 `supplementary`（拓展）。没有该字段表示沿用上游记录，不表示已全面核实。页面中的“可测”仅表示当前允许选题。

待核和拓展内容仍可在图谱中查阅，详情显示理由；诊断列表禁用其目标按钮。整章、整册、全年筛查、直接URL及演示入口采用同一限制。先修回溯不出这些题，答对后也不将它们推断为掌握。结果会单列涉及的待核先修。含这些作答的旧诊断存档不能继续恢复为有效测评，应重新开始；孩子档案里的历史记录仍保留原始历史含义。

## 维护和验证

规则源在 `scripts/align_guangzhou_primary.py`。该脚本修补现有数据，生成核对清单，并同步三个受影响的 `_qbatches/primary_g*.json`。再次运行应当不产生变化；`--check` 完全只读，发现漂移时失败。

```sh
python -X utf8 scripts/align_guangzhou_primary.py
python -X utf8 scripts/align_guangzhou_primary.py --check
npm test
python -X utf8 -m unittest discover -s tests -p test_guangzhou_data.py
python scripts/validate.py
python scripts/check_figures.py
python scripts/verify_questions.py --report .git/verification-guangzhou.json
python -m http.server 8765 --bind 127.0.0.1
```

原 `build_primary.py` 未完整保存上游2026-10-22的手工修订，而且会重写其他学段数据；不要用它重建本分支。需要重新生成小学数据时，先补齐上游生成器，再运行广州修正脚本和全部检查，缺失新增id时脚本会拒绝覆盖。

算法穷举测试使用不附加地域策略的目录输入，继续覆盖全部历史节点；`test_curriculum.js` 单独使用真实生产数据检查广州测评范围、先修回溯、存档和掌握推断。自动答案核验只核验能自动求值的题，不能替代教学内容审校。

GitHub Actions 会执行上述数据、引擎、SVG和答案检查。离线缓存已换版本并包含核对清单、共享策略脚本和独立清单页。本fork默认关闭上游统计地址。
